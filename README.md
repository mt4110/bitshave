# bitshave - 安全・確実な画像ロスレス最適化ツール

**「意味を変えずに、画質を一切落とさず、ファイルサイズだけを減らす。」**

bitshaveは、画像の見た目やピクセルデータを一切変更せずに、不要なメタデータや冗長なビット列を整理することでファイルサイズを削減するコマンドラインツールです。
「AIによる補正」や「非可逆圧縮（画質低下）」は一切行いません。「何も変わらなかった」場合は、正直にそのままのファイルを維持します。

## 🚀 特徴

- **安全第一**: 元のファイルを破壊しません。処理結果が「サイズ増」になった場合は破棄します。
- **ロスレス保証**: ピクセルデータは変更しません。メタデータや圧縮効率のみを最適化します。
- **高速並列処理**: Rustによる実装で、大量の画像もマルチコアで爆速処理します。
- **Nix完全準拠**: 開発・実行環境を `nix` で厳格に管理。依存ツールのバージョンズレによる事故を防ぎます。
- **正直なツール**: 嘘をつきません。削減効果がない場合はスキップします。

## 📦 インストールと実行

本プロジェクトは **Nix** が必須です。

```bash
# Nix環境に入る (依存ツール: oxipng, jpegtran, cwebp, svgo が自動で揃います)
nix develop

# ビルド & 実行
cargo run --release -- --help
```

## 🛠 使い方

```bash
# 現在のディレクトリ以下の画像を最適化 (in-place)
bitshave

# 特定のディレクトリを指定して、結果を別フォルダに出力
bitshave --input ./assets --output ./dist

# 再帰的にサブディレクトリも処理
bitshave --input ./assets --recursive

# Dry-run（実際には変更せず、どれくらい減るか予測を表示）
bitshave --dry-run
```

## 仕組み（Optimization Logic）

このツールが行う「ロスレス最適化」は、引っ越しの荷造りに似ています。

1.  **メタデータの断捨離**: 
    画像の表示には関係のない「撮影日時」「カメラの機種」「作成ソフトの履歴」などの付加情報を削除します。
2.  **収納の達人（圧縮効率化）**:
    画像データ自体（ピクセル）は捨てませんが、その「畳み方（圧縮アルゴリズム）」を最適なものに変えます。同じ内容でも、より効率的に記述し直すことでサイズを減らします。
3.  **厳格な検品**:
    ウイルスやマルウェアが画像に偽装していないか、厳密なヘッダーチェックを行います。
